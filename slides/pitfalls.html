Pitfalls & Proofs

Cycle Deadlock

If A → B and B → A, no node can ever reach an indegree of 0. The algorithm stalls.

Multiple Solutions

A single graph can have several valid topological sorts. Don't expect a single "correct" answer.

Disconnected Graphs

Kahn's algorithm handles multiple components automatically, but DFS requires a loop over all vertices.
