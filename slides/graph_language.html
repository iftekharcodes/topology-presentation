Graph Vocabulary

Vertex (Node)

Represents an individual task or object in the sequence.

Directed Edge

A link u → v indicating task u must occur before task v.

DAG

Directed Acyclic Graph. A graph with no cycles—the mandatory requirement for sorting.

Indegree

Number of incoming edges. Nodes with 0 indegree (Sources) have no prerequisites.
