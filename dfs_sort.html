DFS-based Sort

Recursion First

Visit nodes deeply before processing them. The exploration goes to the end of a path first.

Post-order Rule

A node is added to the sort only AFTER all its neighbors are finished (fully explored).

Reverse Result

Since dependencies finish last in post-order, the final list must be reversed to get the sort.

function DFS(u):
  u.visited = true
  for v in neighbors(u):
    if !v.visited:
      DFS(v)
  result.push(u) // Finished

return reverse(result)
Pro Tip: DFS is excellent for finding strongly connected components and detecting cycles using a recursion stack.
