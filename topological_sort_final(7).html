Introduction to Topological Sorting

Topological sorting is a linear ordering of the vertices of a Directed Acyclic Graph (DAG), where for every directed edge from vertex A to vertex B, A appears before B in the ordering.

It is used to schedule tasks, manage dependencies, and determine the correct order of activities, such as course prerequisites or software installation.

Methodology

Dependencies

If Task B depends on Task A, then A must be completed before B.

Example: Task B depends on Task A.

Task A must be completed before Task B.

Represented by a directed edge A → B

Indegree

Indegree is the number of incoming edges to a vertex. A vertex with indegree 0 has no remaining prerequisites and can be processed immediately.

Example: Task C depends on Tasks A and B.

Incoming edges to C = 2.

Indegree of C = 2.

C can start only after both prerequisites are completed.

Working Process

Start with vertices having indegree 0. Add them to the sorted order, remove their edges, and repeat until all vertices are sorted.

Example: A → C, B → C, C → D

Algorithms Used in Topological Sorting

Kahn's Algorithm (BFS-based): Uses indegree to find vertices with no dependencies and processes them first.

Time & Space Complexity

Time Complexity

O(V + E)

V is the number of vertices and E is the number of edges. The algorithm processes each vertex and edge once.

One pass over vertices + one pass over edges

Space Complexity

O(V)

Extra memory is needed to store the vertices and their sorting order.

Queue and output order scale with the number of vertices
